Dictopen pour Chrome

Alt+Maj+C (ou le bouton de l'extension, ou « Corriger » dans Dictopen) : la sélection si elle existe, sinon le courrier reconnu dans la page (Follow : corps du courrier sans l'en-tête ; ailleurs : le champ de texte actif ou le plus grand éditeur). Le texte est corrigé par Dictopen avec votre clé API, proposé dans un panneau (retraits en rouge, ajouts en vert, modifiable), puis remplacé dans la page.

Niveau de correction, paragraphes non remplis (Follow), volet « Envoyé à Dictopen » et envoi sans vérification se règlent dans Dictopen → ⚙ Réglages → Corriger la sélection ; l'extension les reçoit automatiquement.

Dictopen Le même que dans Dictopen → Réglages → Corriger la sélection (47395 par défaut). Secret partagé avec Dictopen : il prouve que c'est bien l'extension qui demande une correction, et bien Dictopen qui répond. Installée par le bouton de Dictopen, l'extension le reçoit automatiquement ; sinon copiez-le depuis Dictopen → Réglages → Corriger la sélection.

Raccourci clavier : Alt+Maj+C (modifiable dans chrome://extensions/shortcuts).
